# Terceiros e licenças

A Angel Engine é um projeto em desenvolvimento. Este pacote contém código original de integração e usa pacotes do Stride como dependência de terceiros.

- **Stride**: projeto de engine 3D de código aberto, mantido pela comunidade Stride. Repositório: https://github.com/stride3d/stride
- Antes de redistribuir uma versão compilada, confira a licença atual do Stride, as licenças de suas dependências e os avisos exigidos por cada uma.
- Este pacote não inclui o código-fonte completo do Stride e não declara que o código upstream foi escrito por nós.
- O nome “Angel Engine” identifica a camada/projeto de personalização deste repositório; não implica propriedade sobre o Stride.
